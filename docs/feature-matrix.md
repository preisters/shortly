## 해석상 주의

- “기존 구현 유지”는 현재 코드가 완전 검증됐다는 뜻이 아니다. 기준선 테스트와 실제
  CapCut E2E가 필요하다.
- 팀판에서 “제외”인 기능은 CSS로 숨기는 수준이 아니라 route, source, dependency와
  설정 스키마에서 모두 빠져야 한다.
- personal의 “추후 구현”은 이번 문서 작업에서 코드를 만들지 않았다는 의미다.
