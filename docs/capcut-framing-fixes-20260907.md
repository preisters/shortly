# 제작 전 잠재 문제 수정 — 2026-09-07

> 이후 최종 검수에서 발견된 실패 처리·준비 상태 불일치 등은 [내보내기 안전성 보완](export-safety-fixes-20260907.md)에서 수정했다. 아래 준비/커밋 실패 시 잔여 복사본 및 테스트 한계 설명 중 해당 수정과 충돌하는 내용은 최신 보고서를 따른다.

## 적용 범위

이번 변경은 새 내보내기와 새 가이드 생성에 적용된다. 기존 가이드, 생성 원본, 사용자가 편집한 CapCut 프로젝트, 환경 설정과 키는 변경하지 않았다. 유료 생성·실제 영상 제작·서버 재시작·커밋/푸시도 실행하지 않았다. 작업 시작 전부터 있던 다수의 미커밋 변경은 보존했다.

## 수정 내용

1. **원본 보존 배치**: 새 내보내기 두 경로에서 이미지 상단 25% 제거와 영상 9:16 중앙 크롭을 중단했다. 최근 다른 프로젝트의 영상 마스크를 탐색·복제하지 않는다. 소재 템플릿의 마스크/효과 참조도 새 컷에 전이하지 않는다. 의도적으로 붙이는 기존 추천 애니메이션 경로는 유지한다.
2. **공통 표시 영역**: `shortly/core/domain/framing.py`의 `BODY_VIEWPORT`가 이미지/영상에 동일한 전체 보기(contain) 계산을 제공한다. 기본 영역은 화면 왼쪽 7%, 위 30%, 너비 86%, 높이 58%이다. 이는 기존 상단 제목·두 줄 자막을 피하는 보수적인 기본값이며 레퍼런스를 새로 자동 측정한 값이나 모든 채널에 확정된 최적값은 아니다. 가로 영상은 구도를 보존하는 대신 작게 보일 수 있다.
3. **미리보기 일치**: 개인 에셋 화면에 같은 표시 영역 CSS 값을 서버가 주입한다. 9:16 예상도 안에 원본 전체를 표시한다. 이미지 생성 프롬프트도 상단 25%를 비워 달라는 지시를 없앴다. 기존 에셋에 이미 그려진 빈 배경은 임의 제거하지 않는다.
4. **파일 검사**: CapCut의 프로젝트 경로 placeholder를 해석한다. 프로젝트 밖으로 탈출하는 placeholder는 거부한다. 마스크가 없다는 이유로 실패 처리하지 않는다. 마스크·크롭·기본 영역 이탈은 경고한다.
5. **영상 길이**: 로컬 ffprobe(최대 10초)로 실제 길이를 확인하고, 확인된 길이는 소재에 기록한다. 사용 범위가 원본보다 50ms 넘게 길면 컷/파일과 필요 시간을 안내한다. 준비 단계에도 검사한다. 자동 반복이나 유료 재생성은 하지 않는다. ffprobe 미설치/읽기 실패는 길이 미확인 경고이며 검증 성공으로 가장하지 않는다. TTS 확정 타이밍이 뒤에서 달라지면 내보내기 단계에서 추가로 거부될 수 있다.
6. **가이드 덮어쓰기 방지**: 일반 생성과 수정 저장에 원자적 디렉터리 예약을 사용한다. 같은 제목/같은 초/동시 요청도 고유 폴더를 확보한다. 기존 파일·가이드 이름은 일괄 변경하지 않는다.
7. **필수 결말 보호**: 조사 요약, 대본 생성, 팩트체크, 흐름 보정에서 단어 기반 캠페인 배제를 없앴다. 사실 범위를 유지하면서 사용자 지정 필수 결말 → 중심 사건의 직접 결과 → 일반 편집 취향 순으로 판단하도록 했다. 불닭 복귀 파티처럼 중심 사건을 회수하는 행사를 보존할 수 있다. 근거 없는 매출·정부 사과 등을 허용하는 수정은 아니다.
8. **입력·검수 한계 안내**: 필수 내용은 조사/대본 모두 8개×240자로 통일하고 추가 조사는 기존 5개×160자를 유지했다. 화면에 한도와 URL/PDF 읽기 한계를 표시한다. Qwen이 컷 명세 텍스트만 검수함을 명시했다.

## 검증

- 네트워크 연결을 차단한 테스트: 172개 중 156개 통과, 16개 건너뜀. 건너뛴 테스트에는 FastAPI 런타임 의존성이 없는 환경의 웹/API 테스트가 포함된다.
- 임시 템플릿 기반 이미지/영상 실제 export 경로 실행: 원본 바이트와 내보낸 복사본 동일, 템플릿 원본 불변, 마스크 미승계, 원본 크기 보존, 프로젝트 참조 검사 통과.
- 2:3/3:4/9:16/16:9/1:1 원본의 기본 본문 영역 포함 계산 검증.
- 같은 제목의 동시 12회 저장에서 기존 가이드 보존 및 폴더 충돌 없음.
- TTS 레벨 보정, 자막 계약, 영상 음소거, 기존 컷 명세 테스트 포함.
- 개인 에셋 페이지 JavaScript 구문 검사 통과. 실제 HTTP UI와 CapCut 렌더는 미검증.
- 기존 김밥·도시락 프로젝트를 수정 없이 재검사: 각각 에셋 7개·5개 모두 존재 확인, 파일 누락 오류 없음. 기존 마스크는 사용자가 확인할 경고로만 표시된다.

## 사용자 확인 / 후속 범위

서버를 다시 시작한 뒤 개인 에셋 페이지를 새로고침한다. 선택을 유지한 상태로 **내보내기 준비를 새로 실행**한 뒤 새 CapCut 프로젝트에서 한 컷씩 확인한다. 기존 완성 프로젝트에 자동 소급 적용하지 않는다. 세로/가로 영상, 얼굴·손이 가장자리에 있는 이미지, 두 줄 자막을 확인하고 구도에 문제가 없으면 불닭 제작으로 진행한다.

표시 영역을 컷별 드래그/확대/채우기로 편집하는 UI, 채널별 별도 표시 영역 설정, 실제 렌더 프레임을 보는 시각 검수, PDF 전체 읽기는 이번에 구현하지 않았다. 본문 배치 예상도는 자막·제목·효과까지 렌더링한 CapCut 화면이 아니다. CapCut의 버전별 자동 맞춤 해석은 실제 화면 확인이 필요하다.

길이 오류가 발생한 내보내기를 성공으로 취급하지 않는다. TTS 후반 검사에서 실패하면 새 복사 프로젝트가 남을 수 있으므로 해당 복사본을 완성본으로 사용하지 말고 오류를 해결한 뒤 다시 내보낸다. 원본 템플릿과 기존 편집본은 유지된다.
