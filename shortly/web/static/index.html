유튜브 채널 쇼츠를 학습해 같은 느낌의 제작 가이드를 만들어 드립니다.

설정 · AI 연결

분석과 대본 생성에 쓸 AI를 고르고 토큰(API 키)을 넣으세요. 비워두면 간단한 자동 규칙으로만 동작합니다. 키는 이 컴퓨터의 .env 파일에만 저장됩니다.

팀용 포터블 버전입니다. 학습 AI = Claude Sonnet 5, 대본 생성 AI = Claude Opus 4.8 로 고정되어 있습니다. Claude API 키와 CapCut 내보내기용 Typecast TTS API 키를 입력하세요. 키는 이 PC의 사용자 폴더에만 저장됩니다.

학습: claude-sonnet-5 생성: claude-opus-4-8

TTS 키: typecast.ai 에서 발급. 키가 있으면 CapCut 내보내기 때 대본 음성이 자동 생성됩니다.

가이드/대본 생성 전용 모델(선택) · 영상 분석은 위 모델(로컬 등)로 하고, 창작이 중요한 대본 생성만 고품질 상용 모델로 분리할 수 있어요. 비워두면 위 분석 모델을 그대로 씁니다.

현재 생성에 쓰이는 모델:

로컬 팁 · pip install openai 필요.
· 가장 쉬움(Ollama): 텍스트 qwen3.6:27b + 비전 qwen3-vl:8b-instruct-q8_0 (주소 http://localhost:11434/v1).
· 최고 품질(LM Studio): Qwen3.6-27B GGUF + 짝 mmproj 파일을 같은 폴더에 두면 27B가 이미지까지 처리합니다. 주소 http://localhost:1234/v1, 모델명 하나만 넣고 비전 칸은 비워두세요. 16GB VRAM이면 IQ4_XS/Q4_K_M 권장(일부 CPU 오프로딩·느림).
